# cs-300
The problem being solved was handling an intake of data from a file through effective parsing and loading to a suitable data structure to facilitate practical use in an application.

The approach for this this involved doing a series of exercises that roughly accomplished the same task just with different forms of data structures. These structures were important to grasp because they each have their strengths and weaknesses when used. Some are faster, some are more memory-efficient, and others are simply easier to implement. 

Roadblocks were overcome by referring to suitable reference material that showed how each topic worked visually. It was difficult to try to imagine how some of the structures worked just from written descriptions.

This project helped exemplify that there are different approaches to the structure of coding that a developer can use. A working implementation might not be the best implementation.

A lot of the work done on this project involved reusing similar ideas from previous assignments and just modifying the workings of it to accomplish the same task differently. Getting practice with being flexible with my approach for code helped expand my view on how to go about doing things in this manner.
